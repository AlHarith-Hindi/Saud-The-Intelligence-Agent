Tips & keyboard shortcuts
  • Click ✎ Edit to unlock every field on the page — titles, numbers, colors, table headers, tier/status labels, all of it.
  • Ctrl/Cmd + S while editing saves straight to GitHub.
  • Use the ▲▼ arrows to reorder a row, the ⧉ icon to duplicate it, and ✕ twice (click to confirm) to delete it.
  • ↺ Undo reverts the last structural change (add, remove, move, duplicate, color, or import).
  • + Add custom section (bottom of page, in edit mode) creates a brand-new section with its own editable title and list.
  • Click any section title (outside edit mode) to collapse or expand it.
  • Export JSON / Import JSON let you back up or restore the whole dashboard without GitHub.
  • Connect GitHub sync to make edits permanent with full commit history; otherwise changes only autosave to this browser.
